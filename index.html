Publicar online y mantener actualizado
Estructura del archivo
El dashboard funciona como un archivo HTML único con datos embebidos. Para actualizar una publicación web, se reemplaza el archivo publicado por la versión HTML actualizada.
Publicación mediante repositorio web
1
Preparar el archivo
Guardar esta versión como index.html.
2
Subir al repositorio o alojamiento web
Cargar el archivo en el espacio donde se publicará el dashboard.
3
Actualizar datos
Cuando exista una nueva versión del dashboard, reemplazar el index.html publicado por el archivo actualizado.
4
Verificación
Abrir el enlace publicado y comprobar filtros, gráficos, tabla, comparador y exportaciones.
Criterios de control antes de publicar
• Revisar que el nivel activo corresponda al reporte que se desea mostrar.
• Validar que los filtros devuelvan registros esperados.
• Generar una exportación PDF y CSV de prueba.
• Conservar una copia del archivo anterior antes de reemplazarlo.
Características conservadas
• Visualización por Inicial, Primaria y Secundaria.
• Carga de Excel, filtros, comparador, exportación PDF y CSV.
• Datos embebidos en el HTML original, sin depender de una base externa dentro de este archivo.
